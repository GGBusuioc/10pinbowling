# Bowling Score Calculator

Tech Test


## Goal

Create a console app to process a number of games of ten pin bowling, in order to produce a score per game using the included Games.json file.

Some of the games are incomplete, they include strikes, spares, misses and fouls.

You don't need to check for valid throws (assume all the throws were legal).

We've provided some scenarios to process (Games.json), which we expect to be scored correctly. We'll then run some additional scenarios that won't be revealed to you. (Imagine this code was going live with real users)
